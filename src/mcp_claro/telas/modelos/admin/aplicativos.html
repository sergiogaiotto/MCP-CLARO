Aplicativos pausados

A conferência do banco, feita quando o despachante liga, pausou {% if pausados | length == 1 %}este aplicativo{% else %}estes aplicativos{% endif %}. Ela pausa quando o banco pode ter voltado de uma cópia ou quando o vigia não respondeu. Por isso, pode faltar no extrato algo que aconteceu antes, como um bloqueio.

Enquanto um aplicativo está pausado, a entrada recusa os pedidos dele, e nada dele sai para os sistemas. A pausa não sai sozinha, nem quando a porta de saída é reaberta.
